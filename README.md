# Masip Yazdırma Ajanı (Windows)

Masip adisyon sisteminin Windows yazdırma ajanı. Şubenin yazdırma kuyruğunu
dinler, siparişleri ağ (TCP 9100) ve USB termal yazıcılara basar.

**İndir:** [MasipYazdirmaAjani.exe](https://github.com/hasakguldev/masip-yazdirma-ajani/releases/latest/download/MasipYazdirmaAjani.exe)

1. Yazıcının takılı olduğu bilgisayarda exe'yi çalıştırın (kurulum gerekmez).
   Windows "Bilgisayarınız korundu" derse "Ek bilgi" › "Yine de çalıştır".
2. Masip › Ayarlar › Yazıcılar › "Windows Ajanı Bağla" ekranındaki kodu girin.

Ajan yeni sürümleri kendisi indirir ve kurar. Bu repo yalnız yayınları barındırır.
